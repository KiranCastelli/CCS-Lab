Web of Humanity and Spread of Hate

This project is meant to convey the fundmental aspects of society to the future. The core of this project is based on the idea of humanities growth. Eventually, we will reach a point in which humanity develops so fast, that society will look nothing like it has for all of human history. This project is a snapshot of how our intereactions work, and how negativity, war, disease, racism, etc. all spread. It also shows the complexity of our society, how everything, be it social interactions or how history influnces the present, is a web.
